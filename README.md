# project-timeline 線上專案進度時間軸表 https://achir1015.github.io/project-timeline/
<img width="1437" height="975" alt="{F0202AFD-C1AF-4895-BFF5-3871A3A827AE}" src="https://github.com/user-attachments/assets/af5c4833-b7fd-4ea2-96bc-e55397bcfd24" />

一個不用架伺服器、開檔案就能用的排程時間軸表，用 HTML＋內嵌 XML 當資料庫，畫面用 JavaScript 讀 XML、畫成一格一格的時間軸。

畫面結構

橫軸：連續 48 小時，「當日 00:00 → 當日 23:59 → 翌日 00:00 → 翌日 23:59」，每 10 分鐘一格，整點才標文字，避免太密。
縱軸：目前有 5 個班別——白班、小夜班、大夜班、洗澡班、教學班，各自一種顏色，每個班別下面列出它的項目（色塊＝一個項目，長度＝時段）。
凍結窗格：左側「班別/項目」欄與上方時間軸列都固定，上下左右滾動時都看得到，跟 Excel 凍結窗格效果一樣。
現在時間：紅色虛線標示「現在」在軸上的位置。

資料怎麼存
資料放在檔案最上方 <script id="scheduleData"> 裡的 XML，結構是 <shift name=... color=...><task name=... start=... startDay=... end=... endDay=... ><desc>說明</desc></task></shift>。startDay/endDay 用 0（當日）/1（翌日）處理跨夜的班（例如大夜班 22:00→翌日06:00），不用切段，直接畫在同一條軸上。

新增／編輯／刪除

點「＋新增項目」或班別旁的「＋」→ 跳出表單填班別（可直接新增新班別，顏色自動配）、項目名稱、開始/結束時間、說明。
點時間軸色塊或左側項目名稱 → 說明面板顯示內容，可按「編輯」或「刪除」。
⚠️ 這些操作只存在瀏覽器記憶體裡，重新整理頁面會還原成檔案原本的資料。要永久保存，按「匯出目前資料（XML）」把內容複製貼回檔案最上方的 XML 區塊蓋掉舊資料，存檔即可。

技術上的設計方式（配合你的偏好）：JS 用 Shift／ScheduleTask 兩個類別做領域建模，對應 XML 結構；所有時間內部都換算成「絕對分鐘數」（day×1440+時×60+分）方便比較與畫圖；所有註解都是繁體中文。
